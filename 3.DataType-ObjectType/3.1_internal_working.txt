+-----------+

Python Console:

>>> a = 5
>>> b = 2
>>> a
5
>>> b
2
>>> a = a + 2
>>> a
7

+-----------+                          +------------------+
|     a     | -----------------------> |   int object 5   |
+-----------+                          +------------------+
                                              |
                                              |  a = a + 2
                                              v
                                        +------------------+
                                        |   int object 7   |
                                        +------------------+

+-----------+                          +------------------+
|     b     | -----------------------> |   int object 2   |
+-----------+                          +------------------+


Explanation:
- Variables in Python store REFERENCES to objects.
- Integers are immutable.
- `a = a + 2` does NOT modify integer `5`.
- Python creates a NEW integer object `7`.
- Variable `a` now points to `7`.
- Object `5` remains unchanged in memory.
      -> python garbage collector will not immediately collect(remove) 5 because same string/integer values frequently used 
      so python compiler optimised this step to not waste computation in remove and reassign value



a = 5
b = 5       // uses same memory reference of 5 created above(a)
a is b      // True (Python interns small integers for efficiency. 
               CPython keeps a cache of commonly used integers (typically from -5 to 256), so instead of creating new objects repeatedly, it reuses the same object.)

c = 1000
d = 1000
c is d      // Sometimes this is True, sometimes False, depending on how Python created those objects.

a = 5
a = 6       // The sticky note moved; the object 5 did not change.

Before reassignment:
a ─────► [ 5 ]

After reassignment:
a ─────► [ 6 ]

[ 5 ]   (may remain in memory if referenced elsewhere)

# Python Memory Model - list / Set / dict (Mutable Object)

>>> myListOne = [1, 2, 3]
>>> myListTwo = myListOne
>>> myListOne = 'chai'
>>> myListTwo
[1, 2, 3]
>>> myListOne = [1, 2, 3]
>>> myListOne[0] = 33
>>> myListOne
[33, 2, 3]
>>> myListTwo
[1, 2, 3]


Step 1: Assignment creates shared references

+---------------+                     +----------------------+
|  myListOne    | ------------------> |   [1, 2, 3]          |
+---------------+                     +----------------------+
                                             ^
                                             |
+---------------+                            |
|  myListTwo    | ---------------------------+
+---------------+

Python Console:

>>> myListOne = [1, 2, 3]
>>> myListTwo = myListOne

Both variables point to the SAME list object.

----------

Step 2: Reassigning variable creates NEW reference

+---------------+                     +----------------------+
|  myListOne    | ------------------> |      'chai'          |
+---------------+                     +----------------------+


+---------------+                     +----------------------+
|  myListTwo    | ------------------> |    [1, 2, 3]         |
+---------------+                     +----------------------+

Python Console:

>>> myListOne = 'chai'
>>> myListTwo
[1, 2, 3]

- myListOne now points to a NEW string object.
- myListTwo still points to the OLD list object.

---------

Step 3: New list assignment

+---------------+                     +----------------------+
|  myListOne    | ------------------> |    [1, 2, 3]         |
+---------------+                     +----------------------+

+---------------+                     +----------------------+
|  myListTwo    | ------------------> |    [1, 2, 3]         |
+---------------+                     +----------------------+

Python Console:

>>> myListOne = [1, 2, 3]

Now both variables point to DIFFERENT list objects
with same values.

---------

Step 4: Mutating a list

+---------------+                     +----------------------+
|  myListOne    | ------------------> |   [33, 2, 3]         |
+---------------+                     +----------------------+

+---------------+                     +----------------------+
|  myListTwo    | ------------------> |    [1, 2, 3]         |
+---------------+                     +----------------------+

Python Console:

>>> myListOne[0] = 33

Explanation:
- Lists are MUTABLE in Python.
- Changing an element modifies the SAME list object.
- Since myListOne and myListTwo now point to DIFFERENT lists,
  changing one does NOT affect the other.
