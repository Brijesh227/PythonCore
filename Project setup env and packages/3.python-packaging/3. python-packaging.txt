setup.py is used to push package to PyPI
    -> package configuration
    -> package manager 

    Used to define:
      - package metadata
      - dependencies
      - entry points
    
    pip install .

pyproject.toml
    -> same as setup.py but much more efficient

    pip install -r requirements.txt
    
    - Replaces setup.py
    - Standardized (PEP 517/518)
    - Used by tools like:
        - poetry
        - hatch
        - setuptools (modern)

    Sections:
    - build-system
        this section tells build tools what is required to build your package

    - project
        metadata about project
        name = your package created with this name

-----------------------------------------------

Convert requirements.txt to pyproject.toml

1. Current requirements.txt:
    flask==2.3.2
    requests>=2.31.0
    numpy
    pytest
    black

2. same pyproject.toml
    [project]
    name = "my-app"
    version = "1.0.0"
    description = "My backend service"
    dependencies = [
        "flask==2.3.2",
        "requests>=2.31.0",
        "numpy"
    ]

    [project.optional-dependencies]
    dev = [
        "pytest",
        "black"
    ]

3. Install dependencies
    pip install .
    pip install .[dev]

 - Use both like:
    pyproject.toml        👈 source of truth
    requirements.txt      👈 generated for deployment

    generate like:
    pip freeze > requirements.txt
