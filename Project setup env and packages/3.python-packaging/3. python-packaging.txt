Convert requirements.txt to pyproject.toml

1. Current requirements.txt:
    flask==2.3.2
    requests>=2.31.0
    numpy
    pytest
    black

2. same pyproject.toml
    [project]
    name = "my-app"
    version = "1.0.0"
    description = "My backend service"
    dependencies = [
        "flask==2.3.2",
        "requests>=2.31.0",
        "numpy"
    ]

    [project.optional-dependencies]
    dev = [
        "pytest",
        "black"
    ]

3. Install dependencies
    pip install .
    pip install .[dev]

 - Use both like:
    pyproject.toml        👈 source of truth
    requirements.txt      👈 generated for deployment

    generate like:
    pip freeze > requirements.txt

Setup project using poetry:

1. install poetry
pipx install poetry
    // pip -> when you want to Install libraries for project development.
    // pipx -> Install standalone CLI tools for system-wide use. regardless of project like Black, Poetry.

2. initialize your project
for new project
    poetry new my-project

for existing project
    cd my-folder
    poetry init
        - then interaction tool

3. Manage dependencies
Instead of editing the file manually, use Poetry's commands to install dependencies
    poetry add requests
        - This updates your pyproject.toml and creates a poetry.lock file to pin exact versions
        - this install dependencies with ^ symbol
        - for specific use poetry add requests@2.12.1

    poetry install
        - This creates a virtual environment and installs all listed libraries

    poetry shell
        - jump into virtual env to start a project

4. Run and build
    Run project
    poetry run python main.py 

    build project
    poetry build

5. if you want to bump project version
    poetry version minor
        0.2.0 -> 0.3.0

Migrate running project in requirements into poetry

1. initialize project
cd your-project
poetry init
    - interaction promts for project name and version

2. add dependencies from requirements.txt
poetry add $(cat requirements.txt)
    - reads the file and runs poetry add for each library, which resolves versions and creates the poetry.lock file automatically.

3.Handle Development Dependencies
poetry add --group dev $(cat requirements-dev.txt)
    - If you have a separate file for dev tools (like pytest or black), 
    add them to a specific "group" so they aren't included in your production build.

4. Verify and Cleanup
poetry show --tree      # See your new dependency tree
rm requirements.txt     # Safely remove the old file
