Python Packaging
------------------

setup.py → legacy
pyproject.toml → modern

when you do pip install it will fetch package from PyPI(https://pypi.org/)

------------------
requirements.txt
    -> pip install -r requirements.txt
        -r => read mode, read all package and install them

// To create package setup
setup.py is used to push package to PyPI
    -> package configuration
    -> package manager 

    Used to define:
        - package metadata
        - dependencies
        - entry points
    
    pip install .

pyproject.toml
    -> same as setup.py but much more efficient

    pip install -r requirements.txt
    
    - Replaces setup.py
    - Standardized (PEP 517/518)
    - Used by tools like:
        - poetry
        - hatch
        - setuptools (modern)

    Sections:
    - build-system
        this section tells build tools what is required to build your package

    - project
        metadata about project
        name = your package created with this name
